Стек: HTML, SCSS, TS, Vite

Структура проекта:

# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

1. Класс Api
   Фундаментальный компонент для взаимодействия с веб‑сервером. Поддерживает два вида запросов: безопасные (метод GET) и потенциально изменяющие данные (POST, DELETE).

2. Класс Component
   Базовый строительный блок для элементов отображения интерфейса. Предоставляет типовые операции по управлению DOM‑элементами: смену CSS‑классов, установку текстового содержимого, скрытие/показ элементов, настройку изображений и блокировку интерактивных компонентов.

3. Класс EventEmitter
   Реализация шаблона проектирования «Наблюдатель» (Observer). Обеспечивает механизм подписки на события, рассылки уведомлений и отписки от них.

В составе класса предусмотрены:

методы on и off — для регистрации и удаления обработчиков событий;
метод emit — для запуска события и оповещения всех подписчиков;
дополнительные методы onAll и offAll — для глобальной подписки на все события и массового сброса всех зарегистрированных слушателей. 4. Класс Model
Родительский класс для моделей данных. В конструкторе выполняет инициализацию свойств объекта на основе переданных данных, а также предоставляет метод emitChanges для генерации событий при изменении состояния модели.

## Компоненты бизнес‑логики (модели данных)

1. Класс AppState
   Центральная модель состояния приложения. Отвечает за хранение и отслеживание ключевых данных системы. Включает следующие атрибуты:

catalog — список доступных лотов; при обновлении генерирует событие catalog:changed;
basket — набор лотов, добавленных в корзину;
order — текущее состояние заказа;
preview — лот, выбранный для детального просмотра в модальном окне.
Также содержит вспомогательные методы для работы с этими сущностями: проверки наличия товара в корзине, подсчёта общей стоимости, получения идентификаторов товаров, очистки корзины и инициализации заказа.

2. Класс LotItem
   Модель отдельного товара (лота). Наследуется от структуры данных, возвращаемой API, и дополняется логикой управления статусом в корзине. Реализует методы для добавления и удаления товара из корзины, при этом каждое изменение сопровождается событием lot:changed.

3. Класс Order
   Модель процесса оформления заказа. Содержит поля, соответствующие полям форм (способ оплаты, адрес, контакты и т. д.), а также реализует базовую валидацию: проверяет заполненность обязательных полей и формирует список ошибок. Любое изменение данных запускает повторную валидацию и генерирует событие formErrors:changed.

## Компоненты представления (View)

1. Класс Page
   Компонент, отвечающий за отображение всей страницы. Управляет следующими элементами:

counter — счётчик количества товаров в корзине;
galery — сетка карточек товаров;
wrapper — обёртка страницы, позволяющая блокировать прокрутку при открытии модального окна;
basket — кнопка доступа к корзине; клик по ней инициирует событие basket:open. 2. Класс Modal
Компонент модального окна. Позволяет задать:

content — внутреннее содержимое окна;
closeButton — кнопку закрытия.
Автоматически обрабатывает закрытие окна: реагирует на клики по кнопке и по фоновой области, генерируя событие modal:close.

3. Класс Basket
   Компонент корзины покупок. Обеспечивает отображение:

list — списка товаров в корзине;
total — итоговой суммы заказа;
button — кнопки перехода к оформлению заказа, которая вызывает событие order_payment:open. 4. Класс Card
Компонент карточки товара. Предназначен для визуализации отдельного лота в каталоге или в режиме детального просмотра.

5. Класс BasketItem
   Элемент списка корзины. Отображает:

index — порядковый номер позиции;
title — название товара;
price — стоимость единицы;
deleteBtn — кнопку удаления позиции из корзины. 6. Класс Form
Базовый компонент формы. Позволяет настроить:

submit — кнопку отправки;
errors — блок для вывода сообщений об ошибках.
Реализует отслеживание изменений в полях ввода (генерирует события вида container.field:change) и обработку отправки формы (container:submit).

7. Класс DeliveryForm
   Специализированный компонент формы, наследующий Form. Предназначен для ввода данных первой части оформления заказа: способа оплаты и адреса доставки. Управляет полями:

payment — метод оплаты;
address — адрес доставки. 8. Класс ContactsForm
Ещё один специализированный компонент формы на базе Form. Используется для ввода контактных данных:

email — электронная почта;
phone — номер телефона. 9. Класс Success
Компонент экрана успешного оформления заказа. Отображает итоговые данные, полученные от сервера, в первую очередь — общую сумму заказа (total).

## Внешние связи (интеграция с API)

Класс LarekAPI
Обёртка для работы с серверным API. Предоставляет следующие методы:

getLotItem — получение детальных данных по конкретному лоту;
getLotList — загрузка списка всех доступных товаров;
postOrderLots — отправка оформленного заказа на сервер.

interface ILot {
id: string; // уникальный идентификатор товара
title: string; // наименование лота
description: string; // описание товара
image: string; // URL изображения лота
category: ILotCategory; // категория, к которой относится лот
price: number; // стоимость товара
isOrdered: boolean; // флаг: добавлен ли лот в заказ
placeInBasket: () => void; // метод для помещения лота в корзину
removeFromBasket: () => void; // метод для удаления лота из корзины
}

// Модель заказа
interface IOrder {
payment: IPaymentType; // выбранный способ оплаты
address: string; // адрес доставки
email: string; // контактный e‑mail
phone: string; // контактный телефон
items: ILot[]; // список товаров в заказе
formErrors: IFormErrors; // текущие ошибки валидации формы
validateOrder(): void; // выполнить проверку всех полей формы
clearOrder(): void; // сбросить данные заказа до значений по умолчанию
validatePayment(): void; // проверить корректность способа оплаты
validateAddress(): void; // проверить заполненность адреса
validateEmail(): void; // проверить корректность e‑mail
validatePhone(): void; // проверить корректность номера телефона
postOrder(): void; // завершить оформление заказа
}

// Модель состояния приложения
interface IAppState {
catalog: ILot[]; // список доступных лотов
basket: ILot[]; // товары, добавленные в корзину
order: IOrder; // текущее состояние заказа
preview: ILot; // лот, отображаемый в модальном окне
isLotInBasket(item: ILot): boolean; // проверка: находится ли лот в корзине
clearBasket(): void; // очистить корзину от всех товаров
getTotalAmount(): number; // рассчитать общую стоимость товаров в корзине
getBasketIds(): number; // получить идентификаторы товаров в корзине (вероятно, имелся в виду массив ID)
getBasketLength(): number; // получить количество товаров в корзине
initOrder(): IOrder; // инициализировать новый объект заказа
}

// Перечень событий системы
enum Events {
LOAD_LOTS = 'catalog:changed', // загрузка списка доступных лотов
OPEN_LOT = 'card:open', // открытие детальной карточки товара
OPEN_BASKET = 'basket:open', // открытие корзины
CHANGE_LOT_IN_BASKET = 'lot:changed', // изменение статуса лота в корзине (добавление/удаление)
VALIDATE_ORDER = 'formErrors:changed', // запуск валидации формы и обновление списка ошибок
OPEN_FIRST_ORDER_PART = 'order_payment:open', // начало оформления: открытие формы оплаты и адреса
FINISH_FIRST_ORDER_PART = 'order:submit', // завершение заполнения первой формы
OPEN_SECOND_ORDER_PART = 'order_contacts:open', // переход ко второй части оформления (контакты)
FINISH_SECOND_ORDER_PART = 'contacts:submit', // завершение заполнения второй формы
PLACE_ORDER = 'order:post', // финальная отправка заказа на сервер
SELECT_PAYMENT = 'payment:changed', // выбор способа оплаты
INPUT_ORDER_ADDRESS = 'order.address:change', // изменение адреса доставки
INPUT_ORDER_EMAIL = 'contacts.email:change', // изменение контактного e‑mail
INPUT_ORDER_PHONE = 'contacts.phone:change', // изменение контактного телефона
OPEN_MODAL = 'modal:open', // активация модального окна (включение блокировки прокрутки)
CLOSE_MODAL = 'modal:close', // закрытие модального окна (снятие блокировки прокрутки)
}
