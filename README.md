# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

## Базовый компонент интерфейса

Класс Component — основа для всех элементов представления.
Это обобщённый (дженерик) класс: через параметр T он определяет тип данных, которые можно передать в метод отрисовки.

Конструктор: constructor(container: HTMLElement) — получает ссылку на DOM‑узел, за который отвечает компонент.
Поле: container: HTMLElement — хранит корневой DOM‑элемент компонента.
Методы:
render(data?: Partial<T>): HTMLElement — главный метод. Принимает данные для отображения, обновляет внутреннее состояние и возвращает DOM‑узел. В наследниках предполагается реализация сеттеров, которые при вызове render переносят данные в соответствующие DOM‑элементы.
setImage(element: HTMLImageElement, src: string, alt?: string): void — вспомогательная функция для настройки тегов img (задаёт источник и альтернативный текст).

## Модуль работы с HTTP

Класс ServerApi — содержит основную логику сетевых запросов.

Конструктор: constructor(baseUrl: string, options: RequestInit = {}) — принимает базовый URL сервера и необязательный объект заголовков.
Поля:
baseUrl: string — базовый адрес API.
options: RequestInit — конфигурация заголовков, используемая для всех запросов.
Методы:
get(uri: string): Promise<object> — выполняет GET‑запрос к указанному эндпоинту и возвращает промис с данными от сервера.
post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object> — отправляет данные (в формате JSON) на указанный эндпоинт. По умолчанию используется POST, но можно явно задать другой HTTP‑метод.
handleResponse(response: Response): Promise<object> — защищённый метод, который проверяет ответ сервера: при успехе возвращает тело ответа, при ошибке — отклоняет промис.

## Диспетчер событий

Класс EventEmitter — реализация шаблона «Наблюдатель» для обмена сообщениями между частями приложения. Применяется для связи слоя данных и представления.

Конструктор — не требует аргументов.
Поле: \_events: Map<string | RegExp, Set<Function>> — коллекция подписок: ключи — имена событий или регулярные выражения, значения — наборы функций‑обработчиков.
Методы:
on<T extends object>(event: EventName, callback: (data: T) => void): void — подписывается на событие: принимает имя события и функцию, которая будет вызвана при его срабатывании.
emit<T extends object>(event: string, data?: T): void — генерирует событие: передаёт имя и опциональные данные, которые станут аргументом для обработчиков.
trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void — возвращает фабричную функцию: её вызов запускает заданное событие с данными из контекста.

## Структуры данных

Интерфейс IProduct (Товар)
Описывает структуру карточки товара:
id: string — уникальный идентификатор.
description: string — подробное описание.
image: string — ссылка на изображение.
title: string — наименование.
category: string — категория.
price: number | null — стоимость (может отсутствовать).

## Интерфейс Покупатель

Описывает данные клиента:
payment: TPayment — способ оплаты.
email: string — электронная почта.
phone: string — номер телефона.
address: string — адрес доставки.

## Модели предметной области

# Класс ProductCatalog

Управляет коллекцией товаров и текущим выбранным элементом.

Конструктор — без параметров.
Поля:
private products: IProduct[] = [] — список всех товаров.
private selectedProduct: IProduct | null = null — товар, выбранный для детального просмотра.
Методы:
setProducts(products: IProduct[]): void — загружает массив товаров.
getProducts(): IProduct[] — возвращает текущий список.
getProductById(id: string): IProduct | undefined — находит товар по идентификатору.
setSelectedProduct(product: IProduct): void — устанавливает выбранный товар.
getSelectedProduct(): IProduct | null — возвращает выбранный товар или null.

## Класс ShoppingCart

Инкапсулирует состояние корзины покупок.

Конструктор — без параметров.
Поле: private items: IProduct[] = [] — список товаров в корзине.
Методы:
getItems(): IProduct[] — получает содержимое корзины.
addItem(product: IProduct): void — добавляет товар.
removeItem(product: IProduct): void — удаляет товар.
clear(): void — очищает корзину.
getTotalPrice(): number — вычисляет итоговую сумму.
getItemCount(): number — возвращает количество позиций.
hasItem(id: string): boolean — проверяет наличие товара по ID.

## Класс Buyer

Хранит и управляет данными покупателя.

Конструктор — без параметров.
Поля:
private payment: TPayment | null = null — способ оплаты.
private address: string | null = null — адрес.
private phone: string | null = null — телефон.
private email: string | null = null — почта.
Методы:
updateData(data: Partial<IBuyer>): void — обновляет данные.
getData(): IBuyer — возвращает полный объект покупателя.
clearData(): void — сбрасывает данные.
validateData(): Record<string, string> — проверяет корректность данных и возвращает словарь ошибок.

## Уровень взаимодействия с сервером

# Класс ApiClient

Координирует обмен данными с бэкендом интернет‑магазина.

Конструктор: constructor(private api: IApi) — принимает экземпляр API‑клиента для выполнения HTTP‑запросов.
Методы:
async getProducts(): Promise<IProductsResponse> — запрашивает список товаров.
async sendOrder(orderData: IOrderRequest): Promise<IOrderResponse> — отправляет заказ (данные покупателя и состав корзины) и получает подтверждение.
